# ☕ Java Preparation

A personal repository for practicing **Data Structures and Algorithms (DSA)** in Java.

This repository contains solutions, experiments, test cases, and debugging notes for coding questions from multiple platforms such as:

- [LeetCode](https://leetcode.com/u/KrGuddu)
- [HackerRank](https://www.hackerrank.com/profile/krguddu684)
- [GeeksforGeeks (GFG)](https://www.geeksforgeeks.org/profile/krgudd58eo)
- Tutorial and practice questions

## 🎯 Goals

- Strengthen Java programming fundamentals
- Build confidence with DSA problem-solving
- Practice writing clean, readable, and efficient code
- Test edge cases and debug incorrect approaches
- Track progress across different topics and platforms

## 📝 Solution Format

Each solution may include:

- Problem name and source platform
- Problem link
- Approach or algorithm used
- Time complexity
- Space complexity
- Java implementation
- Test cases
- Debugging notes or common mistakes

Example:

```java
// Problem: Two Sum
// Platform: LeetCode
// Approach: HashMap
// Time Complexity: O(n)
// Space Complexity: O(n)
```

## How to Run Java Files

Compile a Java file:

```bash
javac FileName.java
```

Run the compiled file:

```bash
java FileName
```

## 📖 Learning Approach

For every problem:

1. Understand the problem statement.
2. Try a brute-force solution first.
3. Improve the solution using an appropriate data structure or algorithm.
4. Test normal cases, edge cases, and large inputs.
5. Debug carefully and record useful observations.

## Note

These solutions are written for learning and practice. Some problems may have multiple valid approaches, and the code may be updated as understanding improves.

## Progress

Consistency over speed — solving, testing, debugging, and learning one problem at a time.
